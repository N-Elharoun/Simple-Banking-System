# Simple Banking System

A simple banking system built using C# as a console application to practice Object-Oriented Programming (OOP) concepts and basic banking operations.

## Features

- Create a new bank account
- Deposit money
- Withdraw money
- Check account balance
- Input validation for account numbers and amounts

## Technologies Used

- C#
- .NET
- Console Application

## Project Structure

- `Program.cs` - Main application logic and menu
- `BankAccount.cs` - Bank account class 

## How to Run

1. Clone the repository:

2. Open the project in Visual Studio.

3. Build and run the application.

## Sample Menu

```text
Welcome to the Banking System!

1. Create Account
2. Deposit
3. Withdraw
4. Check Balance
5. Exit
```

- Object-Oriented Programming (OOP)
- Classes and Objects
